# MedOS

A personal medical-school study operating system.

`CLAUDE.md` is the product and engineering specification. `BUILD_PLAN.md` is the staged roadmap.
This README is completed at the end of Phase 1.

## Commands

```bash
npm install
npm run dev          # development server
npm run typecheck
npm run lint
npm run test         # unit tests (Vitest)
npm run test:e2e     # production build + Playwright
```
